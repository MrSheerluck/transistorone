Agents are becoming operators, not features

It should be able to prove who it is, hold its own keys, spend inside a limit it can see, remember what it did and leave a receipt. It should not borrow a human's identity, live inside a human's account, or ask a platform for permission to exist.

We are building the open, self-hostable substrate for that: identity, policy, payments, memory and audit as separate components. Run one, or all of them, on your own metal. Use the managed version when you would rather we run it. Humans keep the limits.

The agent is the account.
